Round 3 · Clean slate

Four directions, built on who's actually visiting

The first two rounds framed the page around music vs. corporate. That was the wrong axis, and it's why neither felt right. Three things changed the brief:

Who visits

Every client on file is industry — AEG, Live Nation and C3 are promoters; Clearwing, Clair Bros and 4Wall are rental houses; RockForce is labor. Not one is an end client. The visitor is a production manager checking whether you can take a scope off their plate.

The real range

NFL Draft and Minnesota State Fair aren't concerts. The range you can prove today is scale, not genre — big, complex builds whether or not there's a band. "We also do galas" isn't provable; this is.

Photography

Yes — but one frame at a time, never a collage, graded dark so type sits on black, and always captioned with the event name. A captioned photo works as a credential; an uncaptioned one is decoration.

10Blueprint

One sheet carries the whole page, built up across five phases — survey, infrastructure, structures, circulation, operations. Scope is shown by accumulation rather than a list: the drawing ends up carrying eighty-odd elements across forty-three named layers, with a live element count in the layer manager.

The last step wipes the sheet onto the built event: the photograph comes up behind the linework, so the finished plan stays registered over the real site. Paper, then built — which is the argument the whole page is making.

09Ground Up

The hero draws a site plan over an empty field — boundary, stage, FOH, power runs, truck route — under a plain statement that the plan is drawn before the build. Same team draws it and builds it.

Not reproducible with stock photography, and it leans on the CAD/planning capability you already have. Needs almost no photos, so it can ship now.

Recommendation. 10 Blueprint. It keeps the drawing style from 09 but drops the tidy list of services: scope reads as density on a real sheet, which is closer to what the work actually is. It needs a single photograph, so nothing blocks it. 06 The Roster remains the one to build once five strong frames exist.

Still no photos in the project. Every image is a labeled CSS stand-in cropped exactly where the real shot goes — dropping one in is one line: --img:url('photos/mainstage.jpg'). Priority shots are unchanged: a festival main stage at night, a load-in dawn dock, and a wide of NFL Draft or the State Fair to carry the scale argument.
